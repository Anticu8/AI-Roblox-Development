# Contributing

Thank you for your interest in AI Roblox Development.

This project is focused on practical AI-assisted workflows for Roblox creators.

## Ways to contribute

You can contribute by:

- Reporting bugs or problems with examples
- Suggesting improvements to development workflows
- Sharing useful Luau patterns
- Improving documentation
- Suggesting new examples
- Sharing reproducible AI-assisted development techniques

## Pull requests

For code or documentation changes:

1. Create a branch for your change.
2. Make the change.
3. Explain what the change improves.
4. Open a pull request.

Keep contributions focused and easy to review.

## Issues

When reporting a problem, include:

- What you were trying to accomplish
- What happened
- What you expected
- Relevant Roblox/Luau information
- Reproduction steps when possible

## AI-generated contributions

AI tools may be used during development, but contributors remain responsible
for reviewing and understanding the changes they submit.
